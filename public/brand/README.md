# Brand

The Zaccess mark: a star inside a circle with a Z at its centre.

| File | Use |
| --- | --- |
| [`zaccess-mark.svg`](zaccess-mark.svg) | Source. Transparent, in a mid-tone blue that reads on light and dark backgrounds |
| [`zaccess-mark-256.png`](zaccess-mark-256.png) | Email signatures, linked by its public address |
| [`zaccess-mark-512.png`](zaccess-mark-512.png), [`zaccess-mark-1000.png`](zaccess-mark-1000.png) | Websites, avatars and anywhere a larger raster is needed |
| [`../logo.png`](../logo.png) | The original square logo on its dark background, with the tagline |

> [!NOTE]
> Mail clients show neither SVG nor colour-scheme switching, so the PNGs are drawn to work on both backgrounds rather than as separate light and dark files.

Colour: `#1E8FFF`.
